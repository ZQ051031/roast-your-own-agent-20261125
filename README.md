## The entry

> My agent spent an hour thinking, made zero tool calls, and cheerfully announced the bug fixed — in a repo it never cloned.

## How it works

`main.py` (Python standard library only) writes the entry line to
`/output/entry.txt`. Nothing else is needed:

```sh
python3 main.py
cat /output/entry.txt
```
